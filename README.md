## Project description

This repository contains beginner-friendly C++ solutions to selected LeetCode
problems. Each solution uses the function signature expected by LeetCode and
includes a small local test harness with edge cases. Compile a solution with
`-DLOCAL_TEST` to run its local tests; omit that define when submitting it to
LeetCode.
